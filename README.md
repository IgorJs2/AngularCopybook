# Copybook (Angular): frontend rewrite

> [!WARNING]
> DEPRECATED: an old learning project (2023, unfinished). Archived and no longer maintained. I keep it public to show where I started.
> My current work (Metrocraft 2036 and Stalcraft LAB) is on [my GitHub profile](https://github.com/IgorJs2).

A rewrite of the [Copybook](https://github.com/IgorJs2/CopybookSite) distance-learning platform from React to Angular, built to learn Angular. It covers authorization and about 70% of the class page.

## Tech stack
| Layer | Technologies |
|---|---|
| Frontend | Angular, Angular Material, RxJS, ngx-cookie-service |
| Backend | Node.js, Express, JWT, Mongoose (same API as Copybook) |
